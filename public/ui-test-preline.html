자주 묻는 질문

Preline UI는 Tailwind CSS 기반의 프리미엄 UI 컴포넌트 라이브러리입니다. 현대적인 디자인과 강력한 기능을 제공합니다.

CDN 링크를 추가하고 원하는 컴포넌트를 복사해서 사용하면 됩니다. 매우 간단합니다!

기본 컴포넌트는 무료로 사용할 수 있으며, 프리미엄 버전도 제공됩니다.
